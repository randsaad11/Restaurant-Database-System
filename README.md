# Restaurant Management System

This project is a relational database system designed to manage restaurant operations such as customers, meals, and orders.

## Description
The system is built using a structured database design that includes five main tables:
- Customers
- Orders
- Meals
- Categories
- Order Details

These tables are connected using primary and foreign keys to ensure data consistency and integrity.

## Technologies Used
- SQL
- Microsoft Access
- Python (optional)

## Features
- Organizing restaurant data in a structured way
- Managing customer and order information
- Using SQL queries to retrieve and analyze data
